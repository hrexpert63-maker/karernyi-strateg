# Бот клуба в Telegram

Что умеет:
- **Анонсы**: за сутки до встречи сам готовит черновик и присылает админу; `/announce <id>` - по запросу.
- **Саммари**: `/summary <id>` - из ваших заметок (`notes`) и ссылки на запись.
- **Отсылки к библиотеке**: по расписанию (`DIGEST_CRON`) предлагает материал, который дольше всего не показывали; `/digest` - вручную.
- **Библиотека = видео в чате клуба.** Новое видео, появившееся в чате (или в теме `LIBRARY_TOPIC_ID`), бот сам добавляет в библиотеку и пишет вам: название берётся из первой строки подписи, описание - из остальных. Поправили подпись - описание обновится. Ссылки ведут прямо на сообщение с видео.
- **Гид для участников**: `/guide хочу научиться ...` - 2-4 материала из библиотеки с объяснением, зачем и в каком порядке. `/library` - список. Только для участников клубного чата.

Всё, что уходит в клуб, сначала приходит админу черновиком: «Опубликовать» / «Отмена» / ответом на сообщение дать правки. Исключение - подборки при `AUTO_PUBLISH=true`.
Модель пишет только по данным из `content/` и не рекомендует ничего вне библиотеки. Личные данные участников в `notes` не вносите.

## Как наполнить библиотеку
- **Новые видео**: просто выкладывайте в чат. Подписывайте так: первая строка - название, дальше 1-2 строки, о чём видео. Бот видит только подпись, **не содержимое видео** - без описания он будет рекомендовать по одному названию.
- **Старые видео**: в Telegram Desktop - меню чата - «Экспорт истории чата», формат JSON, без медиа; затем `python import_export.py result.json`. Либо в чате ответьте `/add` на нужное видео.
- **Описания**: `/missing` покажет видео без описания, `/describe tg-123 о чём видео | тема1, тема2` дополнит его (такое описание не затирается подписью).
- Статьи, шаблоны и внешние ссылки можно по-прежнему вести в `content/library.yaml`.

## Запуск
1. Создайте бота у @BotFather, добавьте его **админом** в чат клуба (иначе он не увидит новые видео; чат должен быть супергруппой - обычно так и есть). Для рекомендаций участникам нужно, чтобы бот мог проверять членство в чате.
2. `cp .env.example .env` и заполните.
3. `pip install -r requirements.txt && python bot.py`
   Нужен постоянно работающий процесс (VPS, Railway, Fly и т.п.; Vercel не подойдёт - там нет долгоживущих процессов).
4. Наполните `content/library.yaml` и `content/meetings.yaml` (после каждой встречи - `notes` и `recording`).

Черновики хранятся в памяти: после перезапуска старые кнопки перестанут работать, просто запросите заново.
