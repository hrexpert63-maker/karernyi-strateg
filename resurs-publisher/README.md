# Автопубликация эфиров клуба «Ресурс»

## Как это устроено
После воскресного эфира Zoom запись (mp4) попадает в папку на Google Drive. Туда же Claude кладёт `post.txt` с готовым текстом поста. GitHub Actions каждые 20 минут (воскресенье и понедельник, 08:00–21:00 UTC) запускает `publisher.py`:

1. Находит в папке эфиров подпапки, где есть `.mp4` и `post.txt`, нет `published.marker`, а файлы не менялись 10 минут. Папка `Zoom` и эфиры раньше `START_DATE` (по умолчанию 2026-10-11) пропускаются.
2. Скачивает видео на раннер GitHub (свободно ~14 ГБ, видео до 1 ГБ).
3. Telegram: запускает локальный Bot API server (лимит 2 ГБ) и отправляет видео вторым ботом `@hrexpert_resource_videobot`. Подпись — первая строка поста. Полный текст идёт отдельным сообщением (длинный делится по абзацам).
4. ВКонтакте: `video.save` → загрузка → `wall.post` от имени группы.
5. Ставит в папке эфира метки: `telegram.video`, `telegram.done`, `vk.video`, `vk.done`, а в конце `published.marker`.
6. Присылает вам в личку от второго бота итог (успех или ошибка).

Повторный запуск ничего не дублирует: уже сделанное определяется по меткам. Если упала одна площадка, на следующем запуске повторится только она.

Код лежит в папке `resurs-publisher/` репозитория `karernyi-strateg`, workflow — `.github/workflows/publish.yml`. Папки исключены из сайта через `.vercelignore`.

## Секреты (Settings → Secrets and variables → Actions)
Вносятся командой `gh secret set ИМЯ` (значение вводится интерактивно) или через сайт GitHub. В чат значения не присылайте.

| Секрет | Что это |
|---|---|
| `GOOGLE_SA_JSON` | JSON-ключ сервисного аккаунта Google целиком |
| `DRIVE_FOLDER_ID` | `1utZ8rAZRFFcOO5OVBVGW-KsBV9MA7W7m` |
| `TG_VIDEO_BOT_TOKEN` | токен `@hrexpert_resource_videobot` |
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` | с my.telegram.org |
| `TG_CHAT_ID` | чат публикации (сначала тестовый, потом `-1001940171314`) |
| `TG_NOTIFY_CHAT_ID` | ваш личный chat id для уведомлений (узнать у @userinfobot; бот должен получить от вас `/start`) |
| `VK_TOKEN`, `VK_GROUP_ID` | токен ВК и id группы |

Необязательная переменная `START_DATE` (Variables, не Secrets) — первая дата эфира для обработки.

Токен первого бота (`hrexpert_resource_bot`) здесь не используется.

## Как проверить
Actions → «Публикация эфиров» → Run workflow.
- `dry_run = true`: покажет, что нашёл, ничего не публикуя.
- `dry_run = false`: реальная публикация. Сначала только в тестовые чат и группу.

Тест: создайте в папке эфиров подпапку вида `2026-10-11 тест` с маленьким mp4 и `post.txt`, подождите 10 минут, запустите. Затем запустите ещё раз — ничего не должно задублироваться.

## При сбое
- Письмо или сообщение об ошибке — смотрите лог запуска в Actions, секреты в нём скрыты.
- Если не прошла одна площадка, просто подождите следующего запуска или запустите вручную.
- Ошибка ВК про права/токен: нужен токен пользователя-администратора группы с правами на видео и стену; тип токена проверьте по актуальной документации ВК (dev.vk.com).
- Нет метки на Drive: сервисному аккаунту нужен доступ «Редактор» к папке.

## Как опубликовать эфир заново
В папке эфира на Drive удалите нужные метки. Всё заново: `published.marker`, `telegram.*`, `vk.*`. Только одну площадку: `published.marker` и метки этой площадки (`telegram.video`+`telegram.done` или `vk.video`+`vk.done`). Следующий запуск опубликует.

## Как проверить воскресный запуск
Вечером воскресенья откройте Actions: должны быть запуски по расписанию и зелёная галочка. В личку придёт сообщение. Расписание GitHub может опаздывать на 5–30 минут.
